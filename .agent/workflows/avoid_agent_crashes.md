---
description: 避免代理程式崩潰
---

請依照此指南操作，以防止代理程式執行因錯誤而終止：
1. **確保 API 規範**：在使用 `write_to_file` 建立 Artifact 時，務必填寫 `ArtifactMetadata`。
2. **環境相容性**：在 Windows PowerShell 環境下執行 `npm` 或 `git` 腳本時，優先使用 `cmd /c` 前綴（例如 `cmd /c npm run build`）以避開執行原則限制。
3. **工具存在檢查**：在依賴 `gh`, `hub` 等外部工具前，先執行 `where <tool>` 確認工具是否可用。若不可用，應提供替代方案（如手動 URL）。
4. **防禦性檔案操作**：在執行 `list_dir` 前，先確認目錄路徑是否存在，避免假設路徑結構。
5. **模型容量錯誤處理 (HTTP 503)**：若遇到 `MODEL_CAPACITY_EXHAUSTED` 錯誤，應在重試前等待系統建議的延遲時間（如 11 秒），並考慮簡化下一個請求的內容以減少負載。
6. **任務管理**：避免為過於簡單的操作（如單一搜尋）建立 `task_boundary`，以免觸發系統過濾。
6. **大型變更前研究**：執行重大變更前，先詳閱相關程式碼與環境配置。
